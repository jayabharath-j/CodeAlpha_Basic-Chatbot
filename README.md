# CodeAlpha Basic Chatbot 🤖

A simple rule-based chatbot developed as part of my **CodeAlpha Internship**. This project uses Python and Flask for the backend, with HTML, CSS, and JavaScript for an interactive web-based chat interface.

## 🚀 Features

- Interactive chatbot interface
- Rule-based responses using Python
- Greeting and basic conversation support
- Current date and time responses
- Typing indicator
- Message timestamps
- Automatic scrolling to the latest message
- Responsive user interface
- Error handling for failed requests

## 🛠️ Technologies Used

- **Backend:** Python, Flask
- **Frontend:** HTML, CSS, JavaScript
- **Libraries:** Flask, Python datetime module
- **Tools:** VS Code, Git, GitHub

## ⚙️ Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/jayabharath-j/CodeAlpha_Basic-Chatbot.git
```

### 2. Navigate to the project directory

```bash
cd CodeAlpha_Basic-Chatbot
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the application

```bash
python app.py
```

### 5. Open in your browser

Visit:

`http://127.0.0.1:5000/`
